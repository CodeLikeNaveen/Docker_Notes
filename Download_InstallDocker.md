# Download & install Docker
- [Docker for windows](https://docs.docker.com/desktop/setup/install/windows-install/)

- Open Powershell:
    - Type: ```wsl --install``` then ask for permission **Yes**
        - to enable the Windows Subsystem for Linux (WSL) and download a Linux distribution (such as Ubuntu) directly inside Windows
        -  Build and test apps using Linux-first languages and environments—such as Node.js, Python, Ruby, Docker, and C/C++—without needing a heavy virtual machine or dual-boot setup.
    - wait for installation
    - Restart the computer
    - Test: ```wsl --version```
    - If already install then update: ```wsl --update```
- Double Click: **Docker Desktop Installer.exe**
- Choose: **Per-user installation (Recommended)**
- Choose: **Accept** for Docker Subscription Service Agreement
- SignUp: **Sign Up with Google** || as your wish
