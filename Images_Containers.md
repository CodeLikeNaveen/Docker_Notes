# Images & Containers
- Containers are like hardware machines which runs different OS on them
- Images are like OS which can run inside Containers
- Containers are isolated to each other

- You will build your custom Image

## Sample Code
- Run these:
    - ```docker run -it ubuntu```
        - try fetch the image from loacl 
        - else pull it from **hub.docker.com**
        - run the image in a container
        - **ctrl + D** for exit
    - Test using commands:
        - ```ls```
        - ```whoami```
